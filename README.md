# koceanclimate
## 한반도 주변 상세 해양기후 전망 서비스 
### 주관기관: 서울대학교
### 협력기관: 전남대학교, 부경대학교, 한국해양수산개발원, 한국해양과학기술원

### 수요자
1. 해양기후변화 관련 정책입안,시행자 (중앙/지방 공무원 등)
2. 해양기후변화 교육가 (초중고 교사, 박물관/과학관 연구사 등)
3. 수산업 종사자 (어업, 양식업 등)
4. 해양산업 종사자 (항만시설, 레저 등)
5. 보험회사 (재해, 재난 평가, 보험 산정 등)
6. 학부모 및 학생 (미취학, 유치원, 초등, 중등, 고등)
7. 기후변화 덕후 
8. 그외 대중 (대학생, 중장년)
